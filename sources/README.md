# `sources/` — imported evidence, kept for the record

Everything here came from **outside the repo** and is stored as *evidence*, not as
part of the product. The engine and the pack are in `src/` and `styles/`; nothing
in this folder is imported by a build, a test or a render.

The rule that put it here is AGENTS.md's ownership table: `sources/**` is where
imported material lives, and it is shared — change it only when both owners know.

## Why it exists

The KPOP gold standard (`gate/gold/`) was authored before this repo existed, on a
machine whose working root is `Y:\NewVideoTest`. That root is **not** a git repo,
so its code, its gate toolchain and its proof definitions had no history and no
backup. Two of them are the only record of how the look was built:

- **the gold's own source** — the film that `gate/gold/GOLD.json` pins was
  generated by the code in `gold/`, and
- **the M0 gate toolchain** — the 46 scripts that measured *Same Alarm*,
  *Kpop Crime* and the 25 s proof before `studio/` had its own audits.

## Where to start

If you are the agent taking over M1, read in this order:

1. `docs/M1-HANDOVER.md` — the state, the work order and the traps.
2. `gate/gold/gold-authored-shots.json` + `gate/gold/stills/s01...s54.jpg` — the film
   shot by shot, in words and in pixels, side by side.
3. `sources/gold/analysis/reports/` — *why* each shot looks the way it does. `K` is
   type, camera and cuts; `L` is sets, props and layering; `J-rig` is the body;
   `performance-library` is the poses. The letters A–I cover the acts and the
   misc-en-scène.
4. `sources/gold/acts/` and `sources/gold/pdoom/` — the code that drew it, two
   generations. `pdoom/src/core.js` is the shortest honest answer to "how is a
   frame of this look actually built": one `PAL`, one `paper()` helper, one paint
   wrapper.
5. `sources/m0/proofs/kpop-crime-60/FIXLIST.md` — what M0 got wrong, in the order
   it was found.

## These files are not runnable in place

`m0/scripts/` was written against `Y:\NewVideoTest` — it reads `out/`, `proofs/*/out/`
and `../src`, none of which are here. The scripts are preserved so the *measurement
method* survives, not so they can be re-run. The repo's own equivalents live in
`scripts/` and are the ones that count; when a method here is still wanted, port it
as a typed command with a test, the way `recipes:check` and `gold:stills` were.

The same is true of `gold/acts` and `gold/pdoom`: they are two generations of one
film's source, with different constants (`DUR 156.62` vs `DUR 156.6`, `PAL` vs the
first-generation palette) and neither is wired to the pack. They answer the question
*"how was this look actually drawn?"* — nothing more.
